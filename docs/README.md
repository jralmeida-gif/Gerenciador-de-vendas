# Documentação do Gestor de Vendas

Esta pasta reúne a documentação técnica e operacional do projeto, em português do Brasil.

| Ordem | Documento | Quando ler |
|---|---|---|
| 1 | [`GUIA-INTEGRACAO.md`](GUIA-INTEGRACAO.md) | No primeiro acesso ao projeto. |
| 2 | [`ARQUITETURA.md`](ARQUITETURA.md) | Antes de alterar telas, APIs, D1 ou sincronização. |
| 3 | [`OPERACAO-E-SEGURANCA.md`](OPERACAO-E-SEGURANCA.md) | Antes de operar produção, secrets, backup, push ou Zona de Risco. |
| 4 | [`../CONTRIBUTING.md`](../CONTRIBUTING.md) | Antes de criar branch, pull request ou publicar uma alteração. |

O [`README.md`](../README.md) permanece como porta de entrada do repositório, com a visão geral e os comandos mais usados. A documentação deve ser atualizada no mesmo pull request quando uma mudança alterar arquitetura, operação, secrets, tabelas, rotas ou fluxo de publicação.

> **Regra de atualização:** se uma pessoa nova não conseguir repetir um procedimento lendo os documentos, a documentação ainda não está completa.
